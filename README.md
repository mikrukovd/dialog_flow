# Dialog Flow Bot — Автоматизированный чат-бот

Умный бот-ассистент, использующий **Google Cloud DialogFlow** для распознавания намерений пользователей и автоматического ответов.

## О проекте

Это бот-ассистент для сайта, который:
- **Распознаёт намерения** пользователей через Google Cloud DialogFlow API
- **Отвечает автоматически** на основе базы знаний
- **Работает в двух платформах**: Telegram и VK
- **Логировает события** администратору
- **Ссылка Тг бота** [tg](https://t.me/dialog_flow_test_md_bot)
- **Ссылка Вк бота** [vk](https://vk.ru/club240564467) Нужно написать в сообщения группы

## Функционал

### Telegram-бот
| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и запуск бота |
| Любое сообщение | Обработка через DialogFlow |

### VK-бот
| Функция | Описание |
|---------|----------|
| Слушает сообщения | Через VkLongPoll |
| Автоматические ответы | На основе распознавания интентов |

## Установка

### Установить Python
Убедитесь, что установлен Python 3.8 или выше:
```bash
python --version
```

### Создать виртуальное окружение
```bash
# Windows
python -m venv .venv
.\.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### Установить зависимости
```bash
pip install -r requirements.txt
```

## Конфигурация

### Создать файл `.env`

```env
# ID проекта в DialogFlow Console
PROJECT_ID=

# Токен Telegram-бота (получить в @BotFather)
TG_BOT_TOKEN=

# Токен VK API (получить через vk.com/applications)
VK_GROUP_TOKEN=

# Чат администратора для логов
ADMIN_CHAT_ID=

# Путь к файлу обучения
INTENTS_FILE_PATH=
```

### Как получить токены:

#### Telegram Bot Token:
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Напишите `/newbot`
3. Придумайте имя и юзернейм бота
4. Скопируйте полученный токен

#### VK API Token:
1. Зайдите на [vk.com/applications](https://vk.com/applications)
2. Создайте новое приложение
3. Добавьте виджет "Чат" с правами `messages.write`
4. Получите токен из настроек приложения

## Добавление новых интентов

### Открыть `intents_data.json`

```json
{
    "Название_интента": {
        "questions": [
            "Вопрос 1",
            "Вопрос 2",
            "Вопрос 3"
        ],
        "answer": "Ответ бота на все вопросы из списка"
    }
}
```

### Создать новый интент

```json
{
    "Как связаться с поддержкой": {
        "questions": [
            "Где поддержка",
            "Кому написать",
            "Контакты поддержки",
            "Связь с администратором"
        ],
        "answer": "Для связи с поддержкой напишите на email support@yourdomain.com или позвоните по номеру +7 (XXX) XXX-XX-XX. Мы ответим в течение 24 часов."`
    }
}
```
